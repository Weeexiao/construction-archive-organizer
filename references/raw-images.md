# 散页图片、压缩包及结构页不全

先运行prepare.py inventory。支持PDF、JPG/PNG/TIFF（含多帧）、BMP、ZIP、RAR和7z；RAR/7z使用本机7-Zip，缺依赖明确报出，不能跳过资料后声称完成。工作目录放在输入目录之外，原件不改动。

图片按所在文件夹自然数字排序归并为工作PDF，产生逐张来源及哈希映射。1_2先于1_10；命名中的前缀可作为文件分组线索，不能单凭前缀判定案卷。归并PDF只是识别载体，不能直接认定整个文件夹是一卷。已有Excel/Word目录也要清点读取，按卷号、题名、文件编号与扫描内容对应；不能因目录存在就假定扫描完整。

对每个卷段检查四项：封面、卷内目录（含续页）、正文、备考表。缺封面或缺目录时使用ocr --mode all，逐页识别文件首页/续页/落款/报告编号/日期，结合缩略图校对文件边界。第一张可能就是正文，不得默认删除；目录页中出现“案卷封面”等词也不足以判为封面。原有结构页在excluded_pages列出并保留，不能参与正文页码。

扫描方向逐页检查，横向保存但文字侧倒时先记录方向，OCR时旋转工作图；如需旋正输出，仅在工作副本旋转并记录角度，不覆盖原图。施工方案或报告自带的“目录”是文件正文的一部分，不能当成档案“卷内目录”排除或替换。

已有目录优先作为索引，与实际正文核对；目录条目不能代替缺失正文。跨文件、横向图纸、重复扫描、空白背页和模糊页分别记录，不自动丢弃。项目基本信息包里的其他卷目录不表示这些卷正文已收到，只编入确实收到的材料；未提供卷列缺件，不生成空壳PDF或虚构责任者。

识别后编制reviewed_manifest.json，每卷文件条目都应列source_pdf_pages；没有原纸质页号时以电子正文连续页码编目，page_ref_system为electronic。无目录的文件可从正文标题识别题名，不将图片名机械用作档案题名。责任者、期限及最后一件起止页号仍遵守SKILL.md。

缺封面设source_cover_page为null，由主构建器增加封面。缺目录或备考表的卷增加：

```json
"missing_structure": ["directory", "backup"]
```

已有哪项就不要填写哪项；两项都有可省略。执行：

```text
python scripts/complete_structure.py reviewed_manifest.json --work 工作目录/结构补齐
python scripts/archive_runtime.py build 工作目录/结构补齐/normalized_manifest.json --output 最终成果 --work 工作目录/构建
```

补齐器只在工作副本中插入缺失目录和备考表，重映射正文、责任者证据及卷内条目页序。生成目录自动续页，正文电子编号不含结构页；目录页号采用同卷前面文件填起始页、最后文件填起止页。备考表不伪造签名或纸质原卷事实。补齐后的清单代替原清单供构建、六表、核验和项目登记使用，原始来源映射保留在structure_completed及图片.pages.json。

交付前核验图片总帧数与归并页数、各卷选页无漏判、每条文件边界与目录对应、正文连续页码、结构页不编号、六表记录与PDF档号一致。至少渲染封面、目录首尾页、正文首尾页和备考表，长题名及多页目录尤其需要检查。现成目录与实际不符时保留差异说明，不用猜填消除差异。
