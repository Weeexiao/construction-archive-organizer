# 建设项目扫描档案整理技能

将建设项目扫描资料整理为**六表三级目录 + 按档号命名、带统一封面和正文电子页码的PDF**。

## 完整安装包

**[前往 Releases 下载完整技能包](https://github.com/Weeexiao/construction-archive-organizer/releases/latest)**

下载附件“construction-archive-organizer-v1.1.0.zip”，解压后将整个`construction-archive-organizer`文件夹放入本机`~/.codex/skills/`目录，重新打开Codex会话即可调用。

完整包约749MB，已包含全部业务参考资料。仓库保存技能说明、脚本、六表模板、示例目录及管理制度；10份较大的完整参考PDF随Release安装包分发。使用完整安装包即可取得所有资源，无需再寻找外部参考文件。

## 使用方法

在Codex中提供扫描件文件夹路径，例如：

> 使用 $construction-archive-organizer 整理这个文件夹里的扫描件，输出六表三级目录，以及按档号命名、带封面和正文连续页码的PDF。公司名称填九建公司。

支持PDF、常见图片和ZIP。项目全称从本次材料识别；有正式项目档号时一并提供，没有时先用`SIGJ-JS01-XXXX`占位。

## 最终成果

同一个成果文件夹内直接存放一个Excel和对应PDF。Excel包含六张表，顺序如下：

1. 移交清单
2. 移交目录
3. 预归档登记表
4. 项目级
5. 案卷级
6. 卷内级

案卷题名前加本项目全称；PDF名称与案卷档号一致。封面参照内置示例制作，使用近似牛皮纸底色；正文连续编号，封面、卷内目录和备考表不计入正文页码。过程资料和核对清单另行归档，源扫描件保留。

## 编目要求

- **责任者**按实际形成、编制或出具单位填写，区分施工、监理、设计、检测、发证机关及厂家资料。案卷级汇总该卷形成单位，卷内级逐件填写。
- **公司名称**默认填写“九建公司”，与责任者分开；第三方出具的文件也不因此改变公司归属字段。
- **保管期限**依据包内管理办法逐类判断，整卷取卷内最高期限，不统一套用30年。
- 原目录页号与扫描件不符、文字不清或资料缺失时保留核对事项，不猜填并宣称档案齐全。
